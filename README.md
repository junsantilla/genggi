Greetings, friends! This is the private codebase for the Genggi Website
Genggi is a social network server where users can posts, share profile layouts and talk via chatbox.

## Navigation

- [Genggi Website](https://genggi.com)
- [Contributing Guide](CONTRIBUTING.md)


## What are the features?

- You can freely customize your profile using css.
- Join or Create a chatbox with your friends or for the public.
- Post your stuff, Add friends, Share your profile layouts!
